二、Agentic AI 把需求從 GPU 導回 CPU

主持人引用的數字多數站得住:CPU 占工作負載從 ~15% 升到 50%(Bernstein 2026/6 研報原文 14%→50%)、CPU:GPU 往 1:1 收斂(AMD 官方部落格,並上修 server CPU CAGR 至 35%)。核心數 3,000 萬→1.2 億顆查無原文,但方向與 server CPU TAM 爆發一致。

他也主動打臉網路上「40 顆 CPU 配 1 顆 GPU」的說法:查不到機構背書,較合理的共識是 1:2~1:4。部分大型 CSP 因長期用 Intel、庫存充裕,感受不到 CPU 缺貨。

三、DSP 漲價與 CPO/LPO 辯論

傳一般客戶漲 15–20%、大客戶較少;具體百分比查無新聞證實,但 800G ASP 約 $35–50、1.6T 約 $80–100+ 的行情與供給緊俏屬實。美系 DSP 他點名 Marvell(高階 PAM4 oDSP 市占約 60–70%,與博通合計九成以上)與 MaxLinear(實際市占僅約 1–2%,不同量級)。Qualcomm Hexagon 被拿來說明 DSP 演進到 NPU 的路線,屬科普。
