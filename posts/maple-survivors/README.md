# 楓之谷倖存者：需求、架構、進度

楓之谷 × 吸血鬼倖存者的同人小遊戲。線上：`posts/maple-survivors.html`（遊戲分頁）。
**改這個遊戲之前先讀這份**；做完一個段落就回來更新「進度」與「待辦」。

---

## 1. 原始需求（使用者 2026-10-18 提出）

1. 4 個職業：劍士、弓箭手、法師、盜賊。
2. 等級到了可以 2／3／4 轉。
3. 每次轉職有更多技能可選，包含主動與被動。
4. 升級時有能力點可以點，會增加攻擊力、迴避力、防禦力等。
5. 可以選不同等級的關卡挑戰，包含 BOSS 關；BOSS 首次通關有特殊獎勵。
6. 裝備機制：打怪有機率掉不同素質的裝備和楓幣，也會掉商店買不到的裝備。
7. 楓幣可以在主畫面買一般素質的裝備，或用卷軸強化；卷軸分 100／70／60／30／10，價錢與風險不同。
8. 每場有血量，死亡自動結束並結算經驗；沒完成的話經驗少很多。
9. 動畫、特效、怪物盡量符合原作，但掉落率、升級經驗要調整，避免使用者疲乏。
10. 簡單的紀錄功能：下次打開時，之前的關卡紀錄還在。
11. 要考量效能。
12. 不要在 GitHub 存太多素材。

**後來追加**
- 選職業要更還原：用轉職教官顯示；一個人可以有 4 個存檔欄位。
- 遊戲視窗大小在使用者沒調整視窗時要固定，不能跟著畫面變來變去。

- 難易度最後再調整。
- 手機版晚點再做。
- （2026-10-18）加背景音樂與特效音。
- （2026-10-18）關卡中可切 1／2／4 倍速，也可以強制結束。
- （2026-10-18）遊戲一開始要有仿楓之谷風格的標題畫面。
- （2026-10-18）選單要有原作味道、要有背景；圖鑑能用圖就用圖；內容太長時在遊戲裡面捲，不能撐大遊戲框。

## 2. 定案設計（grill 問答結果）

| 項目 | 決定 |
|---|---|
| 範圍 | 第一期：初心者 → 4 職業 1 轉（Lv10）→ 2 轉分支（Lv30，共 10 條），6 關（含蘑菇王）。第二期：3 轉（Lv60）、4 轉（Lv100）、更多關卡 |
| 職業 | 建立角色不選職業，`job:'beginner'`，創角送 1 SP（`SP_START`）＋新手劍；1 轉時才選職業（能力值自動重置成新職業主屬性、AP 全還、教官送一把武器）。2 轉選 `JOBS[職業].br` 的分支，存在 `br`；選了不能改（跳確認視窗） |
| 語言 | 只做中文；`maple-survivors.en.html` 是佔位頁（CI 要求每篇都有英文頁） |
| 視角／操作 | 俯視自由移動；WASD／方向鍵，手機按住拖曳當搖桿；技能自動施放 |
| 等級 | 遊玩中**不升級**，關卡結束或死亡時才結算經驗 |
| 成長 | 升級得 AP（STR/DEX/INT/LUK，可用楓幣重置）＋ SP（原作式技能樹）。SP 每個轉職階段各自一池（`sp:[初心者,1轉,2轉]`），升級進目前那池、只能點那一轉的技能；每一轉的 SP 不超過那一轉技能點滿所需（`spRoom`：剩下可學等級 − 手上沒點的），所以到下一轉時剛好點完或不夠點，不會有多的；初心者每級 1、1 轉每級 2（1＋20×2＝41，Lv30 剛好點滿 40）、2 轉每級 3。過了下一轉門檻還沒轉：那幾級的 SP 先不給，轉職時一次補到新那池（`advance` 回傳補發數）。帶進關卡的主動技能格：初心者 1、1 轉 2、2 轉 3（3 轉 4、4 轉 6） |
| 關卡內 | 擊倒累積怒氣，集滿三選一「本場限定增益」，出關就消失 |
| 通關 | 一般關撐過 5 分鐘；BOSS 第 3 分鐘出場、時限 10 分鐘，打倒才算通關；關卡依序解鎖 |
| 死亡 | 經驗 30%、楓幣保留、本場撿到的裝備與卷軸沒收；中途「結束」（跳確認視窗）比照死亡 |
| 暫停 | P／Esc 或控制列「暫停」；暫停視窗列出 P 繼續、Q 結束、F 倍速。確認視窗 Enter＝確定、Esc＝取消 |
| 倍速 | 右上控制列一顆鈕循環 1x→2x→4x（快捷鍵 F）：每幀多跑幾次 `update`（不放大 dt，碰撞不穿透）；倍速跨場保留，重新整理回 1x |
| 裝備 | 7 格（武器、帽子、上衣、褲子、鞋子、手套、披風；套服佔上衣＋褲子）；照原作有 Lv＋屬性需求 |
| 飛鏢 | 裝備欄多一格「飛鏢」（`EQ_GRID` 的 `star`），存 `starEq`；只有穿拳套才能裝、才會用（`starUse`），下面一排列出持有的飛鏢，點一下換裝。**沒有數量**：`star:{id:1}`＝持有，有就無限丟（商店每種買一次）。沒裝時自動換上最好的（`starOf`）。雪花鏢、梅之鏢商店不賣，寫在怪物的 `stars` 欄位，只有盜賊會掉（`DROP.star`，已持有的不掉），死亡沒收 |
| 技能頁 | 左 `slotWin`（SKILL SLOT：一格一個、▲▼ 排順序＝關卡技能列順序、✕ 取下）＋右 SKILL 視窗（能帶的主動技能整列可點 `.msv-skr.pick[data-load]` 加入／取下，帶了亮橘底）。出發頁用橫向的 `loadBar` 摘要。排序只影響技能列順序，技能各自冷卻好就放，沒有真正的優先權 |
| 技能欄防呆 | 技能有 `wt` 的，身上武器種類不對就不能帶（技能頁按鈕變「需要短刀」）；換武器後 `hubScreen()` 自動把用不了的技能從技能欄取下並提示。`loadout()` 也依 `wtOk` 過濾 |
| 武器種類 | 原作 14 種（`D.WT`，atlas `itm.wt`）。初心者什麼武器都能拿（防具只能穿共用）；1 轉能拿整個職業的武器；2 轉照 `JOBS.br.wt`：劍客 劍／斧、見習騎士 劍／鈍器、槍騎兵 槍／矛、獵人 弓、弩弓手 弩、刺客 拳套、俠盜 短刀，法師三系都是短杖／長杖。2 轉時身上那把不能用就換下放背包，教官改送分支武器（`D.START_WP`） |
| 掉落 | 每隻怪物各自一張掉落表（依怪物等級）；稀有（楓葉武器）只有蘑菇王會掉 |
| 卷軸 | 照原作：100／60／10 失敗只扣強化次數；70／30 是詛咒卷軸，失敗 50% 爆裝 |
| 存檔 | localStorage＋匯出／匯入 JSON；4 個角色欄位，彼此不共用任何東西 |
| 效能 | 怪物數量不設上限，**不為了效能降難度**（使用者說寧可卡頓） |
| 外觀 | 第一期：每職業每個轉職階段一套固定外觀，2 轉分支各一套（換武器：盾、槍、弩、短刀、杖）；第二期改分層紙娃娃 |
| 素材 | 一次性做成 sprite sheet 存進 repo（圖約 1.7 MB），線上不打第三方 |
| 聲音 | 原作 BGM 5 首（單聲道 32kbps，約 3.1 MB）＋音效 44 個（約 0.4 MB）。選單＝登入畫面曲、s1–s3＝GoPicnic、s4＝SleepyWood、s5＝Nightmare（勇士之村）、BOSS＝BadGuys。遊戲框右下角 ♪ 點開是音樂／音效開關與音量（`.msv-au`），存在 localStorage `msvAudio` |
| 全螢幕 | Alt（Mac 是 Option）＋ Enter：整張 `.card.msv` 進全螢幕，`.msv-stage` 依螢幕取 16:10 最大尺寸置中。標題畫面與角色選擇有提示 |
| 裝備品質 | 掉落時素質浮動總和存成 `q`：>0 藍字、<0 灰字、0 白字（商店貨固定白字，卷軸加的不算）。「賣出灰字」＝背包裡 q<0；「全部賣出」不含身上穿的與稀有裝備；兩個都不賣等級比自己高的（留著升級穿）；都要按兩下。裝備頁「一鍵穿裝」＝`bestGear`：每輪試穿背包裡穿得上的每件，換上分數（攻擊、HP 相對倍數＋減傷）最高的，直到沒有更好的 |
| 畫面 | 選單和遊戲畫布共用一個固定 16:10 的框；選單背景是弓箭手村（`title.webp`），內容放在 `.msv-win` 視窗裡，太長就在視窗內捲 |

## 3. 架構

### 檔案

| 檔案 | 內容 |
|---|---|
| `posts/maple-survivors.html` | 遊戲頁：`.msv-stage`（16:10 框）裡疊著 `#msv` 畫布、`#msv-panel` 選單、`#msv-pick` 三選一。網址＝slug，所以留在 `posts/` 根 |
| `posts/maple-survivors.en.html` | 英文佔位頁 |
| `data.js` | `window.MSD`：所有數值。職業、技能（`SK`）、怪物、關卡、經驗曲線、掉落率、卷軸、怒氣增益。**調平衡只改這支** |
| `game.js` | 引擎＋選單（一個 IIFE）。各段落以 `// ---- 段落名 ----` 分隔 |
| `assets/atlas.js` + `*.webp` | `window.MSA`：素材與物品資料，由工具產生，**不要手改** |
| `tools/build-assets.mjs` | 素材產生器（見下面「素材管線」） |
| `tools/selfcheck.mjs` | 自檢：卷軸機率跑 1 萬次、每隻怪物都有掉落表、每個技能都有圖示（加技能要重跑素材工具）、每個 2 轉分支都有技能、怪物掉的飛鏢都在 atlas、拳套不能帶二連擊、初心者→1 轉→2 轉的 SP 不混池、每轉 SP 不超過技能總和、晚轉補點、一鍵穿裝、全部賣出不賣高等裝。CI 會跑 |
| `assets/site.css` 的 `.msv-*`（站根） | 遊戲 UI 樣式（站上規定只能有一份 CSS，所以不搬） |

除了兩個 HTML 頁和 CSS，其餘都在 `posts/maple-survivors/` 底下（表中路徑相對這個資料夾）。兩支 tools 的 playwright 借用站根 `tools/node_modules`。

### game.js 段落

| 段落 | 做什麼 |
|---|---|
| 素材 | 載圖、`frameAt` 依時間取幀、`spr` 畫圖（原點對齊、左右翻轉） |
| 飛鏢 | 拳套的攻擊（`star:1`：盜賊基本攻擊、雙飛斬）用裝著的飛鏢（`starUse`；裝備欄那格見上面「定案設計」），**無限使用**，飛鏢攻擊力加到武器攻擊（`P.starMul`），飛出去用飛鏢自己的 bullet 圖。沒裝飛鏢基本攻擊改初心者空手。1 轉教官送海星鏢並裝上；盜賊商店多「飛鏢」分頁（每種買一次）。atlas `star` 由素材工具讀 msu `Item/Consume/0207`（`STARS` 清單） |
| 技能要武器 | `SK[].wt`：身上武器種類不對就不帶進關卡（二連擊要短刀、雙飛斬要拳套）。盜賊基本攻擊看武器：`JOBS.thief.atkBy.dagger` 拿短刀近身砍 |
| 物件池／空間網格 | 怪物、投射物、特效、傷害數字、毒霧、掉落物都走 `Pool`；碰撞用 64px 網格 |
| 傷害數字 | 原作 `Effect/BasicEff` 的圖（atlas `ico.num`）：NoRed 打怪、NoCri 爆擊（第一位後墊 `crit` 底圖）、NoViolet 被打／MISS；第一位用 `*1` 大字、其餘 `*0`，字跟字疊 5px。字串（背包滿了、+治療量）照舊用字型 |
| 存檔 | `load`／`valid`／`fix`（補舊版欄位）／`persist`；讀不懂的存檔先備份到 `msvSave.bak`。`skOk`（這角色能學的技能：本職業＋自己分支＋初心者）、`lvUp`（AP＋目前那池 SP）、`advance`（轉職）、`chrKey`（外觀 key）；`window.__msv` 給自檢用 |
| 裝備 | `mkItem`（掉落時素質浮動）、`jobOk`（職業＋2 轉分支武器種類）、`starter`（教官送的武器）、`whyNot`（需求檢查）、`equip`、`useScroll`、`dropTable` |
| 角色數值 | `calc(存檔)` → 戰鬥用數值（攻擊力、HP、減傷、閃避、爆擊、冷卻縮短…） |
| 狀態／生怪／傷害／施放／更新 | 一場戰鬥：`start` → 每幀 `update` → `end` 結算（只有這裡寫入經驗） |
| 繪製／主迴圈／輸入 | 地板鋪磚＋物件、依 y 排序畫角色、HUD |

| 滑鼠提示 | 任何帶 `data-tip` 的元素（`inv:i`／`eqp:部位`／`loot:i`／`id:物品id`）（技能列是 `sk:技能id`）移上去顯示原作式說明框 `.msv-tip`：需求（不足紅字）、職業、數值（跟身上那件比 ▲▼）、剩餘卷軸次數。不是身上那件、且身上同部位有穿時，右邊多一框「目前裝備」。`itIco()` 預設就帶 `id:` |

### 公式

- 攻擊力 ＝ (職業 `base` ＋ 武器攻擊；法師用魔攻) × (主屬性×4 ＋ 副屬性) / 52 × `ATK_K`
- 技能傷害 ＝ 攻擊力 × 技能倍率 × (1 ＋ 被動傷害％ ＋ buff ＋ 本場增益)
- 減傷 ＝ 技能減傷 ＋ 防禦/(防禦＋`DEF_K`)，上限 `DEF_MAX`；關卡中再加 buff 減傷（威嚇、禦魔陣、天使祝福），合計上限 80%
- 閃避率 ＝ 迴避/(迴避＋`EVA_K`)，迴避 ＝ DEX×0.5 ＋ LUK ＋ 技能 ＋ 裝備
- 升級經驗 ＝ `MSD.exp(lv)`

### 存檔格式（localStorage `msvSave`）

```
{v:1, slots:[角色|null ×4]}
角色 = {nm, job（初心者＝beginner）, lv, exp, adv(0 初心者/1/2), br?（2 轉分支）, ap, sp:[初心者, 1轉, 2轉], str, dex, int, luk,
        sk:{技能id:等級}, load:[帶進關卡的主動技能id], st:{關卡id:{best 最久秒數, clears}},
        meso, eqp:{部位:裝備}, inv:[裝備], scr:{卷軸k:數量}, star:{飛鏢id:1}（持有）, starEq（裝著的飛鏢 id／null）, title?}
裝備 = {id, st:{屬性}, tuc 剩餘強化次數, up 成功次數, q 浮動總和（舊存檔由 fix() 補）, req?（新手武器為 0）}
```
加新欄位時在 `fix()` 補預設值，舊存檔才不會壞（例：舊的 `sp` 是數字 → 整包歸目前階段；舊的 2 轉沒有 `br` → 補第一個分支，就是原本那條）。

### atlas 格式（`window.MSA`）

- `ico.items`：`eq`（裝備圖示，`itm[].i` 是序號）、`sc` 卷軸、`meso0`–`meso3`（銅幣／金幣／鈔票／錢袋）；`ico.skills`：`a[技能id]＝[可用, 未學]` 兩幀
- `mob`／`chr`／`skl`／`npc`／`map`／`ico`：`{src:'xxx.webp', a:{動作:[幀…]}}`，幀 ＝ `[x, y, w, h, 原點x, 原點y, 毫秒]`
- `chr` 的 key 是 `職業-轉職階段`（如 `warrior-1`、初心者 `beginner-0`），2 轉分支有自己外觀的是 `職業-2-分支`（如 `warrior-2-spear`）；`map` 的動作是 `bsc`（地板圖塊）與 `obj`（散布物件）
- `snd`：`{bgm:{關卡id|menu: 檔名}, fx:{key: 檔名}}`；fx key：`atk-<職業>`（基本攻擊）、`skl-<技能id>`、`mobd-/mobx-<怪物id>`（受傷／死亡）、其餘照原作檔名（`Portal`、`LevelUp`…）
- `title`：`{src:'title.webp'}` 選單背景（960×600，有損 WebP）
- `itm`：`{物品id:{nm, s 部位, job, wt?（武器種類）, req, rq 屬性需求, st 原始數值, tuc, price, rare?, ov 套服?, i 圖示序號}}`

## 5. 待辦（依優先順序）

1. **難易度**（使用者要求最後再調）。目前只做過一輪：Lv1 新角色用繞圈走位，在第一關約 1 分半倒下；已放慢 s1 生怪、提高職業 HP、受傷無敵 1 秒、`ATK_K` 0.6，之後**還沒重新驗證**。要調的地方都在 `data.js`：`STAGES[].waves` 生怪速度、`MOBS` 血量攻擊、`exp()` 曲線、`DROP` 掉率、`ATK_K`。
   目標：新手 2～3 場到 Lv10；在建議等級的關卡每場升 1～3 級；Lv20 左右能打倒蘑菇王。
2. **手機版**：直式時畫面只有螢幕寬的 16:10、HUD 字太小。要做全螢幕或橫式模式。目前 ≤680px 時角色主畫面退回整個視窗捲（標題不固定）。
3. **英文版**：目前是佔位頁。
4. **第二期**：3 轉（Lv60）、4 轉（Lv100）、更多關卡與 BOSS、分層紙娃娃（穿什麼就顯示什麼；msu.io 的 `Character/*` 有部件與原點）。

## 6. 檔案要不要拆

**現在不用拆，第二期開始前再拆。**

- `data.js`（15 KB）：只放數值，結構單純，不用拆。
- `game.js`（約 80 KB、890 行）：目前靠 `// ----` 段落還找得到東西。不過選單已經佔 240 行、25 KB，第二期會再加 3/4 轉、紙娃娃、更多選單，屆時會超過 1000 行。
- `tools/build-assets.mjs`（220 行）：一次性工具，不用拆。

**第二期前建議拆成三支**（中英頁共用，頁尾依序用 `<script src>` 載入）：

| 新檔 | 內容（對應現在的段落） | 理由 |
|---|---|---|
| `core.js` | 存檔、裝備、角色數值、卷軸、掉落表 | 純邏輯、不碰畫面，自檢可以直接測，改數值規則只動這支 |
| `game.js` | 素材、物件池、網格、戰鬥、繪製、輸入、主迴圈 | 效能敏感的部分集中在一起 |
| `ui.js` | 選單面板全部 | 最常改、最長，跟戰鬥無關 |

拆的時候要注意：
- 現在整支是一個 IIFE，函式彼此靠閉包互相呼叫。拆開後要改成掛在同一個命名空間（例如 `window.MSV`）上，或依載入順序共用全域。
- `window.__msvScroll`／`__msvDropTable` 是給自檢用的出口，拆完要留著或改成 `MSV.useScroll`，並同步改 `tools/selfcheck.mjs`。
