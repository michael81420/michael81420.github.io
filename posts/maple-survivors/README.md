# 楓之谷倖存者：需求、架構、進度

楓之谷 × 吸血鬼倖存者的同人小遊戲。線上：`posts/maple-survivors.html`（遊戲分頁）。
**改這個遊戲之前先讀這份**；做完一個段落就回來更新「進度」與「待辦」。

---

## 1. 原始需求（使用者 2026-10-18 提出）

1. 4 個職業：劍士、弓箭手、法師、盜賊。
2. 等級到了可以 2／3／4 轉。
3. 每次轉職有更多技能可選，包含主動與被動。
4. 升級時有能力點可以點，會增加攻擊力、迴避力、防禦力等。
5. 可以選不同等級的關卡挑戰，包含 BOSS 關；BOSS 首次通關有特殊獎勵。
6. 裝備機制：打怪有機率掉不同素質的裝備和楓幣，也會掉商店買不到的裝備。
7. 楓幣可以在主畫面買一般素質的裝備，或用卷軸強化；卷軸分 100／70／60／30／10，價錢與風險不同。
8. 每場有血量，死亡自動結束並結算經驗；沒完成的話經驗少很多。
9. 動畫、特效、怪物盡量符合原作，但掉落率、升級經驗要調整，避免使用者疲乏。
10. 簡單的紀錄功能：下次打開時，之前的關卡紀錄還在。
11. 要考量效能。
12. 不要在 GitHub 存太多素材。

**後來追加**
- 選職業要更還原：用轉職教官顯示；一個人可以有 4 個存檔欄位。
- 遊戲視窗大小在使用者沒調整視窗時要固定，不能跟著畫面變來變去。
- 圖鑑：列出怪物會掉什麼裝備、每件裝備需要的素質和未浮動數值；進關卡前要知道裡面有哪些怪物。
- 難易度最後再調整。
- 手機版晚點再做。
- （2026-10-18）加背景音樂與特效音。
- （2026-10-18）關卡中可切 1／2／4 倍速，也可以強制結束。
- （2026-10-18）遊戲一開始要有仿楓之谷風格的標題畫面。
- （2026-10-18）選單要有原作味道、要有背景；圖鑑能用圖就用圖；內容太長時在遊戲裡面捲，不能撐大遊戲框。
- （2026-10-19）Alt＋Enter 全螢幕（主畫面要提示）；聲音設定收進遊戲框；裝備滑鼠移上去看數值、名稱藍／白／灰字表示浮動好壞；一鍵賣出灰字／全部；技能依轉職分頁（看不到還沒到的轉職）、有圖示和目前數值說明；裝備圖與楓幣要原版；商店分卷軸／武器／防具。
- （2026-10-19）裝備點選後下方不再列說明（看滑鼠提示）；提示框在有穿同部位裝備時，右邊多一框「目前裝備」比較；裝備欄照原作 EQUIPMENT INVENTORY 排版，沒做的部位先鎖住；圖鑑只留怪物，所有裝備圖示都有提示。

除了兩個 HTML 頁和 CSS，其餘都在 `posts/maple-survivors/` 底下（表中路徑相對這個資料夾）。兩支 tools 的 playwright 借用站根 `tools/node_modules`。

### game.js 段落

| 段落 | 做什麼 |
|---|---|
| 素材 | 載圖、`frameAt` 依時間取幀、`spr` 畫圖（原點對齊、左右翻轉） |
| 物件池／空間網格 | 怪物、投射物、特效、傷害數字、毒霧、掉落物都走 `Pool`；碰撞用 64px 網格 |
| 存檔 | `load`／`valid`／`fix`（補舊版欄位）／`persist`；讀不懂的存檔先備份到 `msvSave.bak` |
| 裝備 | `mkItem`（掉落時素質浮動）、`whyNot`（需求檢查）、`equip`、`useScroll`、`dropTable` |
| 角色數值 | `calc(存檔)` → 戰鬥用數值（攻擊力、HP、減傷、閃避、爆擊、冷卻縮短…） |
| 狀態／生怪／傷害／施放／更新 | 一場戰鬥：`start` → 每幀 `update` → `end` 結算（只有這裡寫入經驗） |
| 繪製／主迴圈／輸入 | 地板鋪磚＋物件、依 y 排序畫角色、HUD |
| 聲音 | `bgm(關卡id／'menu')`、`sfx(key, 音量倍率)`；用 `<audio>`（file:// 直開也能播）；同一音效 70ms 內只響一次、同時最多 10 個。掛點：施放、怪物受傷／死亡、掉裝、撿取、怒氣、結算、轉職、卷軸、商店、按鈕 |
| 滑鼠提示 | 任何帶 `data-tip` 的元素（`inv:i`／`eqp:部位`／`loot:i`／`id:物品id`）移上去顯示原作式說明框 `.msv-tip`：需求（不足紅字）、職業、數值（跟身上那件比 ▲▼）、剩餘卷軸次數。不是身上那件、且身上同部位有穿時，右邊多一框「目前裝備」。`itIco()` 預設就帶 `id:` |
| 裝備欄 | `EQ_GRID`：原作 5×6 格（戒指、墜飾、臉飾…）。key 在 `D.EQ_SLOTS` 裡的才能穿，其餘顯示鎖頭；要開新部位＝`EQ_SLOTS` 加一項＋素材工具抓該類裝備。點一下選取（下方只有操作鈕：穿脫、賣出、卷軸），按兩下直接穿／脫 |
| 選單面板 | 標題畫面（`titleScreen`：自製 logo SVG、開始鈕、怪物在地面巡邏；整片是一顆按鈕，Enter 也行）、角色欄位、建立角色、角色主畫面（出發／能力值／技能／裝備／商店／圖鑑／轉職）、結算、匯出入。`show(h, cls)` 把內容包進 `.msv-win`：`bare`＝不加底色（角色選擇／建立，角色站在場景上）、`title`＝標題畫面撐滿整框、`fix`＝撐滿框，只有 `.msv-scroll` 捲（角色主畫面：角色資訊與分頁固定） |

### 公式

- 攻擊力 ＝ (職業 `base` ＋ 武器攻擊；法師用魔攻) × (主屬性×4 ＋ 副屬性) / 52 × `ATK_K`
- 技能傷害 ＝ 攻擊力 × 技能倍率 × (1 ＋ 被動傷害％ ＋ buff ＋ 本場增益)
- 減傷 ＝ 技能減傷 ＋ 防禦/(防禦＋`DEF_K`)，上限 `DEF_MAX`
- 閃避率 ＝ 迴避/(迴避＋`EVA_K`)，迴避 ＝ DEX×0.5 ＋ LUK ＋ 技能 ＋ 裝備
- 升級經驗 ＝ `MSD.exp(lv)`

### 存檔格式（localStorage `msvSave`）

```
{v:1, slots:[角色|null ×4]}
角色 = {nm, job, lv, exp, adv(0 見習/1/2), ap, sp, str, dex, int, luk,
        sk:{技能id:等級}, load:[帶進關卡的主動技能id], st:{關卡id:{best 最久秒數, clears}},
        meso, eqp:{部位:裝備}, inv:[裝備], scr:{卷軸k:數量}, title?}
裝備 = {id, st:{屬性}, tuc 剩餘強化次數, up 成功次數, q 浮動總和（舊存檔由 fix() 補）, req?（新手武器為 0）}
```
加新欄位時在 `fix()` 補預設值，舊存檔才不會壞。

### atlas 格式（`window.MSA`）

- `ico.items`：`eq`（裝備圖示，`itm[].i` 是序號）、`sc` 卷軸、`meso0`–`meso3`（銅幣／金幣／鈔票／錢袋）；`ico.skills`：`a[技能id]＝[可用, 未學]` 兩幀
- `mob`／`chr`／`skl`／`npc`／`map`／`ico`：`{src:'xxx.webp', a:{動作:[幀…]}}`，幀 ＝ `[x, y, w, h, 原點x, 原點y, 毫秒]`
- `chr` 的 key 是 `職業-轉職階段`（如 `warrior-1`）；`map` 的動作是 `bsc`（地板圖塊）與 `obj`（散布物件）
- `snd`：`{bgm:{關卡id|menu: 檔名}, fx:{key: 檔名}}`；fx key：`atk-<職業>`（基本攻擊）、`skl-<技能id>`、`mobd-/mobx-<怪物id>`（受傷／死亡）、其餘照原作檔名（`Portal`、`LevelUp`…）
- `title`：`{src:'title.webp'}` 選單背景（960×600，有損 WebP）
- `itm`：`{物品id:{nm, s 部位, job, req, rq 屬性需求, st 原始數值, tuc, price, rare?, ov 套服?, i 圖示序號}}`

## 5. 待辦（依優先順序）

1. **難易度**（使用者要求最後再調）。目前只做過一輪：Lv1 新角色用繞圈走位，在第一關約 1 分半倒下；已放慢 s1 生怪、提高職業 HP、受傷無敵 1 秒、`ATK_K` 0.6，之後**還沒重新驗證**。要調的地方都在 `data.js`：`STAGES[].waves` 生怪速度、`MOBS` 血量攻擊、`exp()` 曲線、`DROP` 掉率、`ATK_K`。
   目標：新手 2～3 場到 Lv10；在建議等級的關卡每場升 1～3 級；Lv20 左右能打倒蘑菇王。
2. **手機版**：直式時畫面只有螢幕寬的 16:10、HUD 字太小。要做全螢幕或橫式模式。目前 ≤680px 時角色主畫面退回整個視窗捲（標題不固定）。
3. **英文版**：目前是佔位頁。
4. **第二期**：3 轉（Lv60）、4 轉（Lv100）、更多關卡與 BOSS、分層紙娃娃（穿什麼就顯示什麼；msu.io 的 `Character/*` 有部件與原點）。

## 6. 檔案要不要拆

**現在不用拆，第二期開始前再拆。**

- `data.js`（15 KB）：只放數值，結構單純，不用拆。
