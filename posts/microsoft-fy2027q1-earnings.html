Microsoft．FY2027 Q1 財報拆解

Azure 加速至 48%，毛利率止跌；capex 遞延不能當成投資降溫。
2026-07-01 ~ 2026-09-30公布日:2026-10-282026-10-31草稿完成・尚未發布

TL;DR

  • 營收 $92.279B、YoY +18.8%、QoQ +2.5%；營益 $45.915B，QoQ +13.1%。
  • 毛利率 67.8%，高於上季 67.2%，但低於去年 69.0%；營益率 49.8%。
  • GAAP EPS $4.92；公司剔除 OpenAI 投資影響後 non-GAAP EPS $4.89、YoY +18%。頭條 +32% 不能代表核心增速。
  • 單季 OCF $58.000B − 現金設備購置 $39.367B＝FCF $18.633B；含租賃 capex $45.2B 是另一口徑。

分部與動能

新分部 Agents and Infra $76.795B、年增25%；Devices and Consumer $15.484B、年減3%。前期已重編，不能直接拿舊三分部加總比。商業 RPO $677B、+73%；約30%於未來12個月認列。

指引

FY27 Q2 營收 $96–97.1B，Azure 匯率中性成長 49–50%；Q2 capex 超過 $50B，2026 日曆年約 $170B。遞延第三方產能移至下半財年，管理層仍預期 FY27 FCF 為正。

回頭追認

  • Azure 48% 超過上季約45% CC指引，成長延續。
  • 毛利率從67.2%回升至67.8%，止跌兌現，但仍年減。
  • capex已有量化：本季$45.2B，低於原先約$50B，原因包含交付遞延；投資需求沒有因此證偽。

法說與資料限制

[法說] 官方逐字稿確認第三方交付遞延、CPU/GPU效率改善及 token 單價變化會造成 Azure 季度成長波動；不是所有加速都來自新增機房。Q&A 與反方追問未完成逐題編碼，不臆造追問次數。上季供不應求的敘事仍延續。

估值位階

主要為結構成長，仍受企業支出與投資循環影響。未完成原始報表推導的forward核心EPS模型及當下股價核對，forward PE留—。不以券商目標價、共識預測或trailing PE替代。

風險與反方

AI設備與租賃承諾會讓現金支出、capex與折舊時點分離；本季遞延之後仍可能集中付現。新分部重編及OpenAI投資會扭曲簡單季比。

下季待觀察

  1. Q2 Azure 匯率中性成長是否達49%下緣。
  2. Q2營收是否達$96B，雲端毛利率是否接近65%指引。
  3. Q2 capex是否超過$50B；FCF是否續正。
